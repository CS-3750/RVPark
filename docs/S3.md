# S3 Bucket Setup for RVPark Versioned File Storage

## Prerequisites
- AWS CLI installed and configured with appropriate permissions
- AWS Console access with S3 and IAM permissions

## Step 1: Create S3 Bucket

### 1.1 Create the Bucket
```bash
aws s3 mb s3://rvpark-project-files-[YOUR-UNIQUE-SUFFIX] --region us-east-1
```
Replace `[YOUR-UNIQUE-SUFFIX]` with something unique (e.g., your organization name or random string).

### 1.2 Enable Versioning
```bash
aws s3api put-bucket-versioning \
    --bucket rvpark-project-files-[YOUR-UNIQUE-SUFFIX] \
    --versioning-configuration Status=Enabled
```

### 1.3 Enable Server-Side Encryption
```bash
aws s3api put-bucket-encryption \
    --bucket rvpark-project-files-[YOUR-UNIQUE-SUFFIX] \
    --server-side-encryption-configuration '{
        "Rules": [
            {
                "ApplyServerSideEncryptionByDefault": {
                    "SSEAlgorithm": "AES256"
                }
            }
        ]
    }'
```

## Step 2: Configure Bucket Security

### 2.1 Enable Block Public Access
```bash
aws s3api put-public-access-block \
    --bucket rvpark-project-files-[YOUR-UNIQUE-SUFFIX] \
    --public-access-block-configuration \
    BlockPublicAcls=true,IgnorePublicAcls=true,BlockPublicPolicy=true,RestrictPublicBuckets=true \
    --profile s3-manager
```

### 2.2 Set CORS Configuration
Create a file named `cors-config.json`:
```json
{
    "CORSRules": [
        {
            "AllowedHeaders": ["*"],
            "AllowedMethods": ["GET", "PUT", "POST"],
            "AllowedOrigins": [
                "https://yourdomain.com",
                "http://localhost:5000",
                "https://localhost:7000"
            ],
            "ExposeHeaders": ["ETag"],
            "MaxAgeSeconds": 3000
        }
    ]
}
```

Apply CORS configuration:
```bash
aws s3api put-bucket-cors \
    --bucket rvpark-project-files-[YOUR-UNIQUE-SUFFIX] \
    --cors-configuration file://cors-config.json \
    --profile s3-manager
```

### 2.3 Create Bucket Policy
Create a file named `bucket-policy.json`:
```json
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Sid": "DenyInsecureConnections",
            "Effect": "Deny",
            "Principal": "*",
            "Action": "s3:*",
            "Resource": [
                "arn:aws:s3:::rvpark-project-files-[YOUR-UNIQUE-SUFFIX]",
                "arn:aws:s3:::rvpark-project-files-[YOUR-UNIQUE-SUFFIX]/*"
            ],
            "Condition": {
                "Bool": {
                    "aws:SecureTransport": "false"
                }
            }
        },
        {
            "Sid": "DenyPublicAccess",
            "Effect": "Deny",
            "Principal": "*",
            "Action": "s3:*",
            "Resource": [
                "arn:aws:s3:::rvpark-project-files-[YOUR-UNIQUE-SUFFIX]",
                "arn:aws:s3:::rvpark-project-files-[YOUR-UNIQUE-SUFFIX]/*"
            ],
            "Condition": {
                "StringNotEquals": {
                    "aws:PrincipalServiceName": [
                        "ec2.amazonaws.com",
                        "lambda.amazonaws.com"
                    ]
                }
            }
        }
    ]
}
```

Apply bucket policy:
```bash
aws s3api put-bucket-policy \
    --bucket rvpark-project-files-[YOUR-UNIQUE-SUFFIX] \
    --policy file://bucket-policy.json
```

## Step 3: Create IAM Role and Policy

### 3.1 Create IAM Policy
Create a file named `s3-access-policy.json`:
```json
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Sid": "AllowS3ObjectOperations",
            "Effect": "Allow",
            "Principal": {
                "AWS": "arn:aws:iam::135808920803:user/RVParkApplicationUser"
            },
            "Action": [
                "s3:GetObject",
                "s3:PutObject",
                "s3:DeleteObject",
                "s3:GetObjectVersion",
                "s3:DeleteObjectVersion"
            ],
            "Resource": "arn:aws:s3:::rvpark-project-files-[YOUR-UNIQUE-SUFFIX]/*"
        }
    ]
}
```

Create the policy:
```bash
aws iam create-policy \
    --policy-name RVParkS3Access \
    --policy-document file://s3-access-policy.json
```

### 3.2 Create IAM Role (for EC2/ECS deployment)
Create a file named `trust-policy.json`:
```json
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Effect": "Allow",
            "Principal": {
                "Service": "ec2.amazonaws.com"
            },
            "Action": "sts:AssumeRole"
        }
    ]
}
```

Create the role:
```bash
aws iam create-role \
    --role-name RVParkApplicationRole \
    --assume-role-policy-document file://trust-policy.json
```

Attach the policy to the role:
```bash
aws iam attach-role-policy \
    --role-name RVParkApplicationRole \
    --policy-arn arn:aws:iam::[YOUR-ACCOUNT-ID]:policy/RVParkS3Access
```

## Step 4: Configure Lifecycle Policy (Optional)

Create a file named `lifecycle-policy.json`:
```json
{
    "Rules": [
        {
            "ID": "DeleteOldVersions",
            "Status": "Enabled",
            "Filter": {
                "Prefix": "projects/"
            },
            "NoncurrentVersionExpiration": {
                "NoncurrentDays": 90
            }
        },
        {
            "ID": "DeleteIncompleteUploads",
            "Status": "Enabled",
            "Filter": {},
            "AbortIncompleteMultipartUpload": {
                "DaysAfterInitiation": 7
            }
        }
    ]
}
```

Apply lifecycle policy:
```bash
aws s3api put-bucket-lifecycle-configuration \
    --bucket rvpark-project-files-[YOUR-UNIQUE-SUFFIX] \
    --lifecycle-configuration file://lifecycle-policy.json \
    --profile s3-manager
```

## Step 5: Application Configuration

Add these settings to your `appsettings.json`:
```json
{
  "AWS": {
    "BucketName": "rvpark-project-files-[YOUR-UNIQUE-SUFFIX]",
    "Region": "us-east-1",
    "AccessKey": "YOUR-ACCESS-KEY",
    "SecretKey": "YOUR-SECRET-KEY"
  }
}
```

**Note**: For production, use IAM roles instead of access keys. Store sensitive values in Azure Key Vault, AWS Secrets Manager, or environment variables.

## Step 6: Verification

Test bucket access:
```bash
# Test upload
aws s3 cp test-file.txt s3://rvpark-project-files-[YOUR-UNIQUE-SUFFIX]/test/

# Test download
aws s3 cp s3://rvpark-project-files-[YOUR-UNIQUE-SUFFIX]/test/test-file.txt ./downloaded-test.txt

# Clean up test
aws s3 rm s3://rvpark-project-files-[YOUR-UNIQUE-SUFFIX]/test/test-file.txt
```

## Security Checklist
- [ ] Bucket is private (no public access)
- [ ] Versioning is enabled
- [ ] Encryption is enabled
- [ ] CORS is configured for your domain only
- [ ] Bucket policy denies insecure connections
- [ ] IAM role has minimal required permissions
- [ ] Lifecycle policy is configured to manage costs
- [ ] Access keys are not hard-coded in application
